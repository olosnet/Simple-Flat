# Simple Flat v1.7

## New features

- **New app icon** — Adaptive launcher icon with black background and ring design. Full monochrome support for Android 16+ themed icons.
- **New translations** — Added Spanish, French, Dutch, and Portuguese localizations (in addition to existing Italian).
- **Settings panel background** — Settings and Profile tabs now have a solid surface background instead of being transparent over the fullscreen color.

## Improvements

- **App icon in manifest** — Fixed AndroidManifest so the proper adaptive icon is shown in the launcher.
- **String cleanup** — "Ok" normalized to "OK" across all locales. Removed unused strings.
- **Dependency updates** — Room 2.8.4, Gson 2.14.0, Gradle 9.6.1, Java 11 toolchain.

## Bug fixes

- Fixed RxJava disposable leaks in ConfigsManager and ProfilesManager.
- Fixed deprecation warnings for `setSystemUiVisibility` (proper API 30+ guard).
- Fixed `toLowerCase` locale-sensitive crash risk (explicit `Locale.ROOT`).
- Fixed `Integer.toString()` lint warnings (use `String.valueOf`).
